01About

I started at JUIT in 2025. First semester was C and how memory works, second semester brought object oriented programming in C++, classes, inheritance, and the first data structures. This summer I went deeper into the web, learning HTML that carries meaning and CSS layouts that don’t fall apart the moment someone opens them on a phone.

No frameworks. No template. One HTML file, one stylesheet, written by hand.

Everything I make goes up on GitHub, partly for my university’s summer training and mostly because building in public keeps me honest. If a layout breaks on a phone, the commit history shows me fixing it.

  • Semantic HTML so the page still makes sense without any styling
  • CSS Grid and Flexbox for every layout on this site
  • Custom properties to drive the whole colour theme from one place
  • Git and GitHub for versions and for hosting this page

JavaScript is the next thing on the list, so these panels can eventually remember which one you picked. After that, more data structures in C++ and a third project bigger than this one.
